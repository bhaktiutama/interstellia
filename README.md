# Cooper Station

Simulasi silinder O'Neill yang mengorbit Saturnus: kota, ladang, sungai, trem, lift ke sumbu nol-g, spaceport dengan shuttle yang bisa diterbangkan. Satu file HTML dengan three.js.

## Menjalankan

- Buka `index.html` di browser (Chrome/Edge/Safari terbaru). three.js dimuat dari cdn.jsdelivr.net, jadi perlu internet.
- Atau aktifkan GitHub Pages (Settings > Pages > branch `main`, folder root) lalu buka URL Pages.
- Tekan `/` atau F1 untuk daftar tombol.

## Struktur

| Path | Isi |
| --- | --- |
| `index.html` | Simulasi (versi terbaru) |
| `docs/` | Konsep, tahapan, rangkuman visual, rencana tahap 11 dan 12, gambar |
| `tools/qc_load.py` | Cek cepat: halaman termuat tanpa error (Playwright) |
| `CLAUDE.md` | Konteks proyek untuk Claude Code |

Riwayat tiap tahap ada di git log (satu commit per tahap).
