Uji WebXR

VR0 rencana VR (Oculus Rift CV1, GTX 1060). Halaman ini tidak memakai three.js: hanya mengecek apakah browser bisa membuka sesi VR, berapa resolusi dan FPS-nya, dan apakah kepala, kontroler, dan tombol terbaca.

  1. Pasang software PC Meta (Oculus), Rift terpasang dan terdeteksi. Di software itu: Settings, General, OpenXR Runtime = Oculus (aktifkan bila ada tombolnya).
  2. Buka halaman ini di Chrome, lalu ulangi di Edge. Bila tidak bisa: coba chrome://flags cari "WebXR" atau "OpenXR", atau jadikan SteamVR runtime OpenXR.
  3. Tekan Masuk VR, pakai headset 20 detik, tekan semua tombol Touch (picu, genggam, A, B, X, Y, stik), gerakkan kepala, lalu Keluar VR.
  4. Tekan Salin hasil dan kirim teksnya.
